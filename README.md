# Unity C# StudyLab (Unity 6 6000.x LTS 기준)

초급~고급 커버. C# + 자료구조/알고리즘 + Unity 실무.

## 태그 규칙
형식: `[S스테이지-씬-번호]` 예: `[S04-02-01]`
코드 주석 -> 씬 README -> Stage DeepDive 동일 ID로 연결.
상세: `Assets/_StudyLab/TAG_CONVENTION.md` 참조.

## 전체 목차 (B안)
- Stage00_Setup: 환경 + C# 마인드셋 [2씬]
- Stage01_CSharpBasic: C# 기초 + Unity 기초 [5씬]
- Stage02_UnityMid: Unity 중급 시스템 [5씬]
- Stage03_CSharpAdv: C# 심화 [4씬]
- Stage04_DataStructure: 자료구조 시각화 [6씬]
- Stage05_Algorithm: 알고리즘 시각화 [5씬]
- Stage06_MiniGame: 통합 미니게임 [3씬]
- Stage07_UnityAdv: 고급 Unity (URP/Addressables/Job) [5씬]
- Stage08_Practice: 실무 패턴 + 빌드 [4씬]

각 Stage 폴더 안에 `Scenes/`, `Scripts/`, `DeepDive.md` 포함.
각 씬 폴더 안에 `README.md` 포함.
