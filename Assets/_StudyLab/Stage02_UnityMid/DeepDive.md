# Stage02 DeepDive — Unity 중급 연결

## 목표
물리, 시간(Coroutine), UI 이벤트, SO 데이터 분리, 오브젝트 풀을 연결한다.

### [S02-01-01] 심화: 물리는 힘/속도로
- Rigidbody는 물리 스텝(FixedUpdate) 단위로 적분, transform 직접 변경은 충돌 검사 우회
- 혼용 증상: 벽 통과(터널링), 진동, 충돌 콜백 누락
- 규칙: 물리 객체 이동은 AddForce/velocity, 순간이동만 MovePosition

### [S02-01-02] 심화: Collision 물리 반응
- `isTrigger=false` 쌍방 + 최소 한쪽 Rigidbody → 접촉점·법선·상대속도 제공
- 반발은 `contacts[0].normal` 방향 힘, 마찰/반발계수는 Physics Material로 조정
- 초급: 튕기기 / 중급: 데미지+넉백 / 고급: Continuous 충돌 모드와 터널링

### [S02-01-03] 심화: Trigger 감지
- 물리 반응 없이 통과 + 이벤트만, 코인/골대/시야 판정에 사용
- 조건: 한쪽 Collider isTrigger + 한쪽 Rigidbody(보통 이동 측)
- 2D/3D 계열 혼용 불가, 레이어 충돌 매트릭스로 불필요 판정 제거

### [S02-02-01] 심화: Update 타이머
- 매 프레임 `timer += deltaTime` 후 임계 비교, 단순·직관적
- 비용: 일회성 지연에도 매 프레임 분기, 타이머가 늘면 Update 비대화
- 적합: 쿨타임 UI 갱신처럼 매 프레임 표시가 필요한 경우

### [S02-02-02] 심화: Coroutine yield
- `yield return new WaitForSeconds`로 대기 중 함수 일시정지, Update 분기 불필요
- 시간 스케일 영향: 일시정지 동반 멈춤, 무시하려면 WaitForSecondsRealtime
- 주의: 문자열 기반 Start/Stop 금지, 메서드 참조/IEnumerator 핸들 보관

### [S02-02-03] 심화: 중복 실행 방지
- 같은 루틴 중복 Start = 타이머 2개 병렬 → 배속·이벤트 중복
- 패턴: 시작 전 Stop, 실행 중 플래그, 핸들 저장 후 StopCoroutine
- `Restart()`는 StopAll + Start 최소 예제, 실전은 루틴별 핸들 관리

### [S02-03-01] 심화: Action 이벤트 분리
- UI는 표시만, 점수 변경 사실은 `Action<int>`로 방송 → 구독자가 각자 처리
- 결합도 감소로 버튼/점수 로직 독립 테스트 가능
- 초급: 직접 참조 / 중급: Action 분리 / 고급: 이벤트 버스·UniRx 맛보기

### [S02-03-02] 심화: 코드 AddListener
- 인스펙터 onClick 연결은 씬 의존·누락 추적 어려움, 코드는 컴파일 추적 가능
- 명명 메서드로 등록/해제 쌍 유지, 람다 등록은 해제 불가로 누수 원인
- null 가드 + 경고로 미연결을 Play 즉시 발견

### [S02-03-03] 심화: 구독 해제
- 이벤트가 파괴된 객체 참조 유지 → 호출 시 MissingReference/누수
- 쌍 규칙: Awake 구독 → OnDestroy 해제, Start 등록 → OnDestroy 제거
- 정적 이벤트는 씬 전환 후에도 잔류, 해제 누락 시 전역 버그로 확산

### [S02-04-01] 심화: 데이터 에셋 분리
- SO = 코드 없는 데이터 컨테이너, 기획자가 인스펙터로 수치 조정·복제
- 효과: 밸런스 패치가 코드 수정·재컴파일 없이 에셋 교체로 해결
- 프리팹이 SO 참조 → 같은 적/아이템 종류를 에셋 스왑으로 양산

### [S02-04-02] 심화: OnValidate 검증
- 인스펙터 값 변경 시 에디터에서 자동 호출, 음수·범위 초과를 저장 전에 교정
- 런타임 가드와 역할 분담: 에셋 오입력은 OnValidate, 실행 중 예외는 코드 가드
- 주의: 빌드 실행 중에는 호출 안 됨, 런타임 검증 별도 필요

### [S02-04-03] 심화: SO 참조 보관
- 인벤토리는 SO 원본 참조만 List에 보관 → 원본 수정이 전 인벤토리에 즉시 반영
- 복사본 보관 시 원본 패치 무효 + 메모리 중복, 동기화 버그 유발
- 개수(스택)는 별도 구조(SO+count 쌍)로 관리, 다음 단계 학습 주제

### [S02-05-01] 심화: Queue 풀
- Dequeue/Enqueue O(1), 선입선출이라 특정 객체 편중 사용 방지
- `List.RemoveAt(0)` O(n) 이동과 대비, S04 Queue 스폰과 동일 원리
- 초급: 고정 풀 / 중급: 동적 확장 / 고급: 파티션·스레드 맛보기(개념만)

### [S02-05-02] 심화: SetActive 재사용
- Instantiate(메모리 할당+초기화)와 Destroy(GC 예약)를 풀 회전으로 제거
- 총알처럼 빈번·단명 객체에서 프레임 스파이크 해소 효과 최대
- 빈 풀 정책: 신규 생성(무한정 아님, 상한+경고가 실전형)

### [S02-05-03] 심화: 반환 null 가드
- 파괴된 객체를 풀로 되돌리면 다음 Get에서 예외, 반환 전 null 검사가 방파제
- 한발짝: Release에서 위치/속도/상태 초기화까지 담당 → 꺼낸 즉시 사용 가능
- 실전 풀: Get/Release 외에 Preload/Warmup/Trim(축소) API 추가
