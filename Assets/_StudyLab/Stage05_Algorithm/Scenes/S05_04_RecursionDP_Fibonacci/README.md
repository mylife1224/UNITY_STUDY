# S05_04_RecursionDP_Fibonacci

## 학습목표
같은 피보나치를 순수 재귀 vs 메모이제이션으로 돌려 호출 횟수 차이로 DP 이해

## 조작법
1. 빈 GameObject에 `DP_Fibonacci.cs`를 붙이고 Play
2. Console에서 두 방식의 호출 횟수·시간 비교 (n=20 기준 수천 회 vs 수십 회)
3. Inspector에서 `N`을 25/30으로 키워 격차가 기하급수적으로 벌어지는지 확인 (30 초과 주의)
